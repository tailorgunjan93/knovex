Windows 10 / 11 — 64-bit
⇓ Knovex-Setup.exe .exe · NSIS
Run the installer → Next → Next → Install → Finish.
Knovex appears in Start Menu & Desktop automatically.

SmartScreen on first run? Click “More info → Run anyway”.

macOS
macOS 12 Monterey and later
⇓ Knovex.dmg .dmg · x64
Open the .dmg → drag Knovex to Applications → launch.

Features

A complete AI workspace

Built for privacy-conscious professionals who want real control over their data.

💬
Document Chat
Ask questions across PDFs, Word docs, and Markdown via hybrid FTS5 + semantic RAG.
🧠
Knowledge Bases
Organise files into named KBs. Index once, query forever at ~1 ms latency.
🔍
Semantic SearchNew
Dense vector embeddings via local ONNX model (~45 MB) or OpenAI Embeddings API.
🎓
Learn Mode
8 formats: quiz, flashcards, mind map, timeline, story, ELI5, speed-learn, brainstorm.
🔧
Any LLM Provider
OpenAI, Anthropic, Groq, Gemini, Bedrock, Ollama — swap without restarting.
🔒
Encrypted at Rest
API keys stored with Fernet AES-128. Your secrets never leave your machine.
🌐
Web Search
Ground answers in live results via DuckDuckGo, Serper, or Brave Search.
📋
Document Reader
In-app rendering for PDF, DOCX, XLSX, CSV, Markdown — no external viewer needed.
📊
File Summaries
One-click brief or detailed summary of any file or entire knowledge base.

Why Knovex

Privacy isn’t a checkbox.
It’s the foundation.

Most AI tools send your documents to third-party servers for indexing and retrieval. Knovex inverts this: your files, your vectors, your database — all on your machine. The LLM call is the only optional network hop.

✓

Zero document upload — files are indexed locally with SQLite FTS5 and optional ONNX embeddings.

✓

No telemetry, no analytics — Knovex never phones home. Check the source.

✓

Use Ollama for 100% offline — combine with a local LLM and your data never leaves the machine.

✓

Fernet-encrypted API keys — stored in your OS user directory, unreadable by other users.

Get started

Up and running in minutes

No Python, Node.js, or terminal required. Just download and install.

1

Download & Install

Run the installer for your OS. The backend, frontend, and database are all bundled inside.

2

Configure an LLM

Open Settings → LLM. Paste your OpenAI, Anthropic, or Groq key — it’s encrypted immediately.

3

Upload documents

Drag PDFs, DOCX, XLSX, or text files into a Knowledge Base. Knovex indexes them in seconds.

4

Chat & Learn

Ask questions with cited sources, run web search, or open Learn Mode for interactive content.
