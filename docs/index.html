Windows

Windows 10 / 11 — 64-bit

⬇ Knovex-Setup.exe

Run the installer → click Next → Next → Install → Finish. Knovex will appear in your Start Menu and on your Desktop.

Windows Defender may show a SmartScreen prompt on first run — click "More info → Run anyway".

🍎

macOS

macOS 12+ (Intel & Apple Silicon)

⬇ Knovex.dmg

Open the .dmg, drag Knovex to Applications, then double-click to launch.

On first open macOS may say the app is from an unidentified developer — right-click → Open to bypass.

🐧

Linux

Ubuntu 20.04+ / Debian / any x64 distro

⬇ Knovex.AppImage ⬇ knovex_amd64.deb

AppImage — works on any distro. Make executable and run:
chmod +x Knovex-*.AppImage && ./Knovex-*.AppImage

.deb — Ubuntu/Debian:
sudo dpkg -i knovex_*_amd64.deb

Up and running in 3 steps

1

Download & Install

Run the installer for your OS. Knovex installs in seconds — no Python or Node.js required.

2

Add your API key

Open Settings → LLM. Paste your OpenAI, Anthropic, or any compatible API key. Keys are encrypted at rest.

3

Upload & Chat

Drag and drop your PDFs, DOCX, or TXT files into a Knowledge Base, then start asking questions.

4

Learn anything

Use Learn Mode to turn any topic into a quiz, flashcards, story, mind map, or timeline.
