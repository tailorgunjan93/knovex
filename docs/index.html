Windows says "Don't run" or "Unrecognised app"?

Knovex is open-source and unsigned. Windows SmartScreen flags all new unsigned apps. Two quick steps to proceed:

  1. Browser download bar — Chrome / Edge may show a warning. Click the ⋯ or ^ next to the file → Keep → Keep anyway.
  2. SmartScreen popup — "Windows protected your PC" appears. Click More info (small link, bottom-left) → then the blue Run anyway button.
  3. The installer opens normally. Knovex is installed to your user folder — no admin password required.

02Features

Everything you need,
nothing you don't.

Built for privacy‑conscious professionals. All compute runs on‑device. Cloud is optional — and only ever for the LLM call.

🔍
Semantic Search New
Dense vector embeddings via local ONNX (~45 MB, one‑time download) or the OpenAI Embeddings API. Hybrid FTS5 + ANN + RRF fusion for best recall.
💬
Document Chat
Ask questions across PDFs, Word, Excel and Markdown via RAG. Every answer cites the exact page and section it came from.
🧠
Knowledge Bases
Organise files into named KBs. Index once, query at ~1 ms with SQLite FTS5. Stale‑file detection keeps the index in sync automatically.
🎓
Learn Mode
Turn any document or topic into a quiz, flashcard set, mind map, timeline, story, ELI5, speed‑learn or brainstorm session.
🔧
Any LLM Provider
OpenAI, Anthropic, Groq, Gemini, AWS Bedrock, Cerebras, Ollama — swap without restarting. Powered by LiteLLM under the hood.
🔒
Encrypted at Rest
All API keys are stored with Fernet AES‑128 symmetric encryption. Keys live in your OS user directory, readable only by your account.
🌐
Web Search
Ground answers in live web results via DuckDuckGo (free), Serper.dev or Brave Search. Toggle per chat — sources cited inline.
📄
Document Reader
In‑app rendering for PDF, DOCX, XLSX, CSV and Markdown. Inline Q&A on any open file — no switching to an external viewer.
📊
File Summaries
One‑click brief or detailed summary for any file or an entire knowledge base. Exportable as Markdown.
03Setup

Up and running in four steps.
Or fewer, if you use Ollama.

Installation is identical across platforms — pick your model provider once, drop in your documents, and ask away.

STEP 01

Download & install

Run the installer for your OS. Knovex installs in seconds — backend, frontend and database all bundled. No Python or Node needed.

STEP 02

Add a model

Open Settings · LLM and paste an OpenAI, Anthropic or Groq key — or point to a local Ollama. Keys are encrypted on save.

STEP 03

Build a knowledge base

Drag and drop PDFs, DOCX, XLSX or Markdown into a KB. Knovex chunks, indexes with FTS5, and optionally embeds for semantic search — all locally.

STEP 04

Chat & learn

Ask questions with cited sources, toggle web search, or hit /learn to generate a quiz, flashcard set, story, mindmap or timeline.
