Download

One-click install

Available for Windows, macOS, and Linux. No dependencies required.

🖼️
Windows
Windows 10 / 11 — 64-bit
⇓ Knovex-Setup.exe .exe
Run the installer → Next → Next → Install → Finish.
Knovex appears in Start Menu & Desktop automatically.

SmartScreen on first run? Click “More info → Run anyway”.
🍎
macOS
macOS 12 Monterey and later
⇓ Knovex.dmg .dmg
Open the .dmg → drag Knovex to Applications → launch.

First launch: right-click → Open to bypass Gatekeeper.
🐧
Linux
Ubuntu 20.04+ · Debian · Any x64
⇓ Knovex.AppImage portable ⇓ knovex_amd64.deb Ubuntu / Debian
AppImage:
chmod +x Knovex-*.AppImage && ./Knovex-*.AppImage

Debian / Ubuntu:
sudo dpkg -i knovex_*_amd64.deb

Features

Everything you need

A complete AI workspace built for privacy and productivity.

💬
Document Chat
Ask questions across PDFs, Word docs, and Markdown files via RAG.
🧠
Knowledge Bases
Organise documents into named KBs with hybrid FTS5 + semantic retrieval.
🎓
Learn Mode
8 formats: quiz, flashcards, mind map, timeline, story, ELI5, speed-learn, brainstorm.
🔧
Any LLM Provider
OpenAI, Anthropic, Groq, Gemini, Bedrock, Ollama — swap without restarting.
🔒
Encrypted at Rest
API keys stored with Fernet encryption. Your secrets never leave your machine.
🌐
Web Search
Ground answers in live results via DuckDuckGo, Serper, or Brave Search.

Get started

Up and running in minutes

No Python, Node.js, or terminal required.

1

Download & Install

Run the installer for your OS. Everything is bundled — no extra setup needed.

2

Add your API key

Open Settings → LLM. Paste your OpenAI or Anthropic key. It’s encrypted immediately.

3

Upload documents

Drag PDFs, DOCX, or text files into a Knowledge Base and Knovex indexes them instantly.

4

Chat & Learn

Ask questions, get citations, or open Learn Mode to turn any topic into interactive content.
